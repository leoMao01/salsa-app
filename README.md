# Salsa piste par piste

Application web pour apprendre le pas de base de la salsa (1-2-3, 5-6-7) sur un vrai groove, puis construire un orchestre couche par couche : clave, congas, bongó, campana, güiro, maracas, timbales, basse, piano.

- `index.html` : toute l'application.
- `samples/` : percussions et piano enregistrés, extraits de la [Versilian Community Sample Library](https://github.com/sgossner/VCSL) (licence CC0). La basse et la cáscara sont synthétisées.
