# Salsa piste par piste

Application web (un seul fichier `index.html`) pour construire un groove de salsa couche par couche : clave, congas, bongó, campana, güiro, maracas, cáscara, basse, piano.

Tous les sons sont synthétisés en direct (Web Audio), aucun fichier audio requis. Fonctionne sur iPhone (Safari / app Claude).
